First release of Dainvo Office: Writer, Calc and Impress for macOS, Windows and Linux, based on LibreOffice.

- Dainvo look: new icons, ribbon toolbars and a reworked Start Center.
- Gelasio and the Intos font families are included, and documents that use Georgia or Aptos show with matching fonts.
- Language packs are downloaded automatically when you use a new language.
- Updates: macOS and Windows copies update themselves; Linux shows a notice when a new version is out.
